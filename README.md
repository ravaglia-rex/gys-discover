# discover.globalyoungscholar.com

The parent-facing campaign page for the GYS Discovery (₹299) AppLovin campaign. A static page, served by GitHub Pages.

- `index.html` is the page. Edit `window.GYS_CONFIG` at the top for the sign-up link and price.
- `media/` holds the video, its poster and the share image.
- `CNAME` tells GitHub Pages to serve the page at discover.globalyoungscholar.com.

The AppLovin pixel base code goes where the page says `APPLOVIN_PIXEL_BASE_CODE`.
